# Game VFX Portfolio - Product Requirements Document

## 프로젝트 개요

게임 VFX 아티스트들이 자신의 포트폴리오를 관리하고 공유할 수 있는 웹 애플리케이션입니다.

## 목적

- VFX 작품 온라인 포트폴리오 관리
- 작품 전시 및 공유
- 포트폴리오 통계 및 분석
- 협업 및 피드백 시스템

## 핵심 기능

### MVP (Minimum Viable Product)

1. **프로젝트 관리**
   - VFX 작품 등록/수정/삭제
   - 작품 메타데이터 관리 (제목, 설명, 이미지, 동영상)
   - 카테고리 분류

2. **포트폴리오 전시**
   - 공개 포트폴리오 페이지
   - 그리드 레이아웃 표시
   - 작품 상세 페이지

3. **사용자 관리**
   - 회원가입/로그인
   - 프로필 설정
   - 포트폴리오 공개/비공개 설정

## 기술 스택

- **Frontend**: Next.js 16+, React 19, TypeScript, Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Deployment**: Vercel
- **Version Control**: Git, GitHub

## 사용자 스토리

1. **VFX 아티스트**
   - "나는 내 VFX 작품들을 온라인에 업로드하고 싶다"
   - "내 포트폴리오를 잠재적 고용주에게 공유하고 싶다"
   - "작품별 조회수와 피드백을 추적하고 싶다"

2. **포트폴리오 방문자**
   - "공개된 VFX 포트폴리오를 볼 수 있다"
   - "작품 상세정보와 메타데이터를 확인할 수 있다"

## MVP 범위

### 포함 항목
- 기본 CRUD 기능
- Supabase 인증
- 이미지 저장소
- 반응형 UI
- TypeScript 타입 안정성

### 제외 항목 (Phase 2+)
- 고급 분석
- 협업 기능
- 댓글/평가 시스템
- 결제 기능
- PWA/모바일 앱
